# bayan — поиск дубликатов файлов

Утилита командной строки для поиска дубликатов файлов по содержимому.
Файлы сравниваются поблочно: каждый файл разбивается на блоки заданного
размера, блоки хешируются, и файлы с совпадающими последовательностями
хешей считаются дубликатами.

Учебный проект OTUS (задание 8). C++23, Boost (program_options, hash2),
GoogleTest для тестов.

## Сборка

Требуется CMake >= 3.12 и компилятор с поддержкой C++23. Зависимости
(Boost, GoogleTest) подтягиваются автоматически через FetchContent.

```sh
cmake -B .build
cmake --build .build -j8
```

Бинарь: `./.build/bayan`.

Тесты собираются по умолчанию (`WITH_TESTS=ON`); отключить — флагом
`-DWITH_TESTS=OFF` при конфигурации. Запуск тестов:

```sh
cd .build && ctest --output-on-failure
```

## Использование

```
bayan [опции] <директория...>
```

Позиционные аргументы — одна или несколько директорий, в которых
ищутся дубликаты (обязательно).

## Параметры

| Короткая | Длинная        | Назначение                                                             | По умолчанию |
| -------- | -------------- | ---------------------------------------------------------------------- | ------------ |
|          | `--help`       | Вывод справки и выход с кодом 1                                        |              |
| `-E`     | `--exclude`    | Исключаемые директории (можно указывать несколько)                     |              |
| `-D`     | `--depth`      | Глубина обхода; 0 — только указанная директория, без вложенных         | `INT_MAX`    |
| `-F`     | `--min-size`   | Минимальный размер файла в байтах                                      | `1`          |
| `-M`     | `--file-masks` | Маски имён файлов (можно несколько; `*` и `?`, не зависят от регистра) |              |
| `-S`     | `--block-size` | Размер блока чтения/хеширования в байтах                               | обязательно  |
| `-H`     | `--hash`       | Алгоритм хеша: `crc32`, `md5` или `sha1`                               | обязательно  |

Правила и ограничения:

- `-S` и `-H` обязательны: без них запуск завершается ошибкой с кодом 1.
- Некорректные значения опций (`-S abc`), неизвестные опции и повторное
  указание скалярной опции — ошибка `Command line error: ...`, код 1.
- Значение `-S` меньше 1 — ошибка `Wrong block size specified!`, запуск завершается с кодом 1.
- Значение `-D` меньше 0 трактуется как «без ограничения» (по умолчанию обход
  тоже не ограничен); значение `-F` меньше 1 заменяется на 1.
- `-D N` ограничивает поиск файлами не глубже N уровней от корня
  (N = 1 — файлы в корне и в его непосредственных поддиректориях;
  N = 0 — только указанная директория, без вложенных;
  по умолчанию и при N < 0 — без ограничения).
- Несуществующие директории — и в позиционных аргументах, и в
  `--exclude` — молча игнорируются, ошибкой это не является.
- Файлы, которые не удалось открыть или прочитать (нет прав, ошибка
  ввода/вывода), в поиске не участвуют; в stderr выводится сообщение
  с путём к файлу.
- Опции `-E`, `-M` можно повторять несколько раз; списки суммируются.
- Позиционные директории, `-E`, `-M` принимают несколько значений
  подряд, например `bayan d1 d2 -E e1 e2`.

## Вывод

Дубликаты выводятся группами: каждая группа — файлы с одинаковым
содержимым, по одному пути на строку. Группы разделяются пустыми
строками. Файлы, для которых дубликатов не нашлось, в вывод не
попадают.

```
/данные/фото/отпуск.jpg
/данные/бэкап/отпуск.jpg

/данные/архив/отчёт.pdf
/данные/старое/отчёт.pdf
```

## Примеры

Поиск дубликатов в одной директории (блок 4 КБ, хеш crc32):

```sh
bayan ~/photos -S 4096 -H crc32
```

Несколько директорий:

```sh
bayan /data/a /data/b -S 1024 -H md5
```

Исключение служебных директорий:

```sh
bayan . -E ./.build ./node_modules -S 1024 -H sha1
```

Поиск только изображений (маски задаются несколько раз):

```sh
bayan . -M "*.jpg" -M "*.png" -M "*.gif" -S 1024 -H crc32
```

Ограничение глубины — не глубже двух уровней от текущей директории:

```sh
bayan . -D 2 -S 1024 -H md5
```

Только файлы размером от 1 МБ:

```sh
bayan /mnt/backup -F 1048576 -S 4096 -H crc32
```

Комбинация опций:

```sh
bayan /srv/upload /srv/archive -E /srv/upload/tmp -D 3 -F 1024 \
  -M "*.pdf" -M "*.docx" -S 4096 -H sha1
```

Полный список опций:

```sh
bayan --help
```
